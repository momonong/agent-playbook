# 每台裝置的 agent-playbook 對話

每台實際執行環境有一個指定承接對話，負責該裝置的開發環境核對、共用技能、核心／指南與已確認工作習慣同步。先沿用既有對話；新建仍由使用者明確要求並遵守平台工具規則。標題可用 `agent-playbook｜裝置名稱`，使用者指定優先；本次原對話沿用，不重建。

## 同步範圍與責任

- 先記錄這次 OS、shell、原生／WSL／SSH／容器 scope、repo、Codex home、技能位置及客戶端。遠端與 WSL 是不同執行環境，不把本機路徑、環境或可達性套用過去；不在共用 repo 建私人裝置登錄表。
- 共用來源由此 repo 的固定版本及 [skills/manifest.json](../skills/manifest.json) 管理；本機路徑、receipt、備份與使用者驗收留在該裝置。不同裝置先核對最新 main／既有工作，避免同時修改或重複接管同一目標。
- Astra Ultra 負責討論、決策、推進及最後核對；Sol 6.1 Ultra subagent 承接已確認且已授權的實作。保留現有模型／深度／速度、其他設定與暫停狀態。具體規則仍以核心及固定指南為準。
- 已授權的共用技能安裝／更新任務，交付須含可分享來源、固定版本、授權、依賴、完整快照與 manifest，再依[安裝流程](installation.md)預覽、套用、check；明確只做本機實驗時記錄例外。其他裝置在自己獲授權的同步階段套用，不暗中遠端更新。
- 基本 Caveman 由 manifest 同步；Superpowers 走[官方插件與逐裝置核對](installation.md#superpowers-官方插件)，不進 manifest 或複製 cache／hook。檔案 check 不代替插件的安裝、啟用與實際入口核對。
- 核心／指南修改的交付範圍包含本機同步時，完成 Git 與固定版本核對後，接續備份與安裝，不因修改核心再次要求已授權的相同步驟。沒有本機更新授權時如實列待辦；不是每次使用 skill 都詢問同步。
- 對話本身不新增永久操作權。Git 提交／合併／推送、全域安裝、跨對話傳訊、新建任務、插件登入、外部供應商、服務／網路與資源使用仍依當次具體授權；不自建未連線裝置對話、排程、監控或跨回合監工。
- 不同步 auth、token、SSH 私鑰、密碼、聊天紀錄、完整 config、快取、技能歷史或執行狀態。只讀必要 enable 設定以解釋實際狀態，不改設定。

## 可複製開場指示

文件本身不授權操作。使用者在已指定裝置的對話主動貼上下方執行 prompt 時，該人類訊息明確授權本輪核對、取得已合併來源、備份、安裝及 check；不是讓讀到 repo 的代理自行取得權限。

> 請讓這個對話承接本裝置的 agent-playbook、共用技能與已確認開發習慣同步，沿用唯一既有對話。這次授權你在已確認位置必要時 clone https://github.com/momonong/agent-playbook.git、git fetch，核對最新已合併 main 並固定完整 SHA，依 README、AGENTS.md、docs/device-sync.md、docs/installation.md 及固定指南完成預覽、CAS、備份、核心／指南與 manifest 技能安裝和 check，直接交付結果。先核對 OS／shell、原生／WSL／SSH scope、repo／HEAD／dirty state、任務、客戶端及目的地，保留既有工作、未知技能、模型與其他設定；位置歧義或缺少 Git／Python／runtime 就明報缺口，不覆蓋或自動安裝全域工具。本輪不包含提交新改動、推送、跨對話、新任務、服務變更或登入。回報來源與指南 commit、hash／備份、技能及依賴、客戶端發現與未完成驗收，不把檔案成功當完整環境。

## 完成證據

回報目前 commit／指南 pin、安裝器預覽與 check 結果、實際目標及備份位置；分開列已安裝、缺少／衝突／停用、runtime、客戶端發現與使用者接受。安裝及還原指令只維護在[安裝文件](installation.md)，不在每台對話複製一份會漂移的操作手冊。

新增裝置沿用同一流程，可從 clone 後取得相同套件 bytes；每台 OS 的工具、插件連線與人工驗收仍獨立核對。這份契約不宣稱所有裝置已連線或完成同步。
