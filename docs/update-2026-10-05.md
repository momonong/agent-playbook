# 2026-10-05 國網訓練文件入口

使用者準備從其他研究專案使用國網資源，要求更新本 repo 的文件管理、版本、合併與推送；其他位置由使用者另行處理。本輪只調整 agent-playbook，不修改 selfhost-models、研究 repo、Codex 全域設定或執行國網操作。

## 需求與文件對應

| 需求 | 更新位置與行為 |
|---|---|
| 新研究對話能找到國網操作文件 | [核心](../instructions/codex.md)新增國網／NCHC／Nano5 訓練及 Slurm 準備的觸發條件；[服務指南](../guides/service-integration.md#國網訓練selfhost-models)提供專用入口 |
| 跨裝置原樣使用 | 沿用已指定／登錄位置、PROJECTS_ROOT、原生 home 候選；缺少本機副本可唯讀取得可追溯的 GitHub 版本，不要求手改路徑或自行 clone |
| 操作文件有單一來源 | selfhost-models 維護 docs/nchc-codex.md 及其操作／樣本引用；playbook 只保存文件路由與共通限制 |
| 研究工作與參考文件分開 | code、環境、job、manifest 與結果留在原研究 repo；參考 repo AGENTS 不覆蓋研究 repo 規則 |
| 參考版本可重現 | playbook 指南依核心 guides-commit；外部參考另外記完整 commit、路徑與查閱日期，同一 run 更新時核對影響，不靜默取最新草稿 |
| 延續既有授權及證據邊界 | 離線準備、唯讀 preflight、短 GPU smoke、完整訓練分清授權與驗收；不把讀指南或 CPU 樣本成功當成可花額度或 GPU 訓練通過 |

維護時已讀 selfhost-models 的 0.3.0rc3 國網指南（commit `83109ed6ea87a2f6c7d198c4a35c09f1f75f1387`）。這是入口設計的依據，不宣稱帳號、配額或研究環境目前可用。未變更模型配置、角色、批准政策，也不恢復已停止的共用平台擴充。

## 使用者更新方式

1. 從 main 的 [instructions/codex.md](../instructions/codex.md) 複製完整原文，替換 Codex 個人指示並儲存；Windows、Linux、macOS 使用相同文字。
2. 不需另貼四份指南、README、操作筆記或研究 job；也不需為此修改既有批准用途的 Custom rules。文件引用由代理按條件讀取，不是平台自動匯入。
3. 新開工作階段核對載入新版核心；不要假設既有對話自動重新載入。需要離線指南快照時，另依 [安裝流程](installation.md) 在已授權裝置更新，本次不自動安裝。

驗證包含 diff、UTF-8、Markdown 連結／指南路徑、核心大小及可攜性、歷史原文 SHA-256、四份指南與新 pin 一致性。既有安裝測試及三平台 CI 驗證安裝行為，不能當成國網連線、GPU 訓練或所有平台國網操作已通過。
