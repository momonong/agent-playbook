# 2026-10-10 外部 CLI task 與 Markdown 交接

使用者希望減少 Codex 用量，確認所指為 Google Antigravity CLI（agy），並要求保留 main／orchestrate／task／optional learn 的協作架構。使用者同意以工作複雜度選擇短指令或 Markdown 交接，最後授權修改本 repo 文件及提供完整可複製核心。

## 需求映射

| 需求 | 文件與行為 |
|---|---|
| 保留角色、替換 task 執行工具 | [核心](../instructions/codex.md)與[合作指南](../guides/collaboration.md)定義 task 責任單位，可由 Codex 或已授權外部 CLI 承擔；保留標準及精簡路徑 |
| 避免多一層轉傳成本 | 外部 task 記任務與 session ID，不要求另建 Codex task 或虛構 Codex 對話識別 |
| Markdown 可交接，簡單工作也能外派 | [外部執行指南](../guides/external-execution.md)區分短指令與文件，規格及結果分開；不強制小工作填大型模板 |
| 降低重複推理與重做 | task 完成範圍內實作／測試／除錯，協調者核對 diff 與必要證據；沿用正確 session、精簡回傳、不重貼整份歷史 |
| 外部供應商及操作授權可追溯 | 明確確認階段、供應商、資料、操作、資源與停止條件後，範圍內持續執行不重問；平台拒絕與敏感資料保護不變 |
| 模型表不錯套到 agy | [模型指南](../guides/model-selection.md)將原模型預設限於 Codex；外部設定獨立確認，未指定新的外部預設模型或 effort |
| 可原樣複製完整核心 | 新增按需入口，指南先固定為本機 commit，再更新核心 guides-commit 與 URL；安裝測試核對第六份指南及快照 |

learn 主軸與 main 的決策／驗收／回報責任保留。外部 CLI 派工是可追溯的 task 交付，不授權 main／orchestrate 自行修改實作，也不預設所有工作都轉給 agy。

## 驗證與交付範圍

- 本輪只維護本 repo 與本機版本，未實際派發 agy task、傳送專案內容給外部模型、修改 CLI 認證／批准設定、安裝全域指示、建立新對話或排程。
- CLI 依據為 2026-10-10 本機 agy 1.3.2 version／help 與外部指南所列官方文件；尚未有實際 task 的端到端驗收或節省比例證據。
- 核對 diff、UTF-8、Markdown 路徑／連結、歷史原文 hash、核心大小與可攜性、六份指南版本一致，以及既有安裝測試中的快照內容。跨平台 CI 在後續 GitHub 交付時核對，未執行不宣稱通過。
- 完整可複製來源為 `instructions/codex.md`，包含新版指南 pin；只追加外部 task 段落會漏掉版本與入口。Custom rules 不需因本次新增執行工具而放寬。
- 本機指南 commit 尚未推送時，其他裝置無法經 GitHub 取得；完成另行授權的推送／合併後，再從 GitHub main 複製正式版。工作分支、本機提交、GitHub 交付與全域設定生效分別回報。
