# 2026-10-20 HTML 可讀交付與預覽服務決策

## 確認範圍

使用者確認 HTML 統整與說明須能在使用者當前裝置渲染閱讀，內建或外部瀏覽器皆可；不能以執行端 localhost 或不可達絕對路徑充當交付，也不為每個說明頁啟動臨時服務。規則放在全域指示及工程指南，不客製 `answer-me-with-html` 上游 skill。

通用交付規則集中於[工程指南的 HTML 交付章](../guides/engineering.md#html-交付)：先核對使用者可取得成品與實際預覽通道，同機且工具允許時直接開啟；跨裝置沿用已驗證且獲授權的入口。檔案產生、上傳／發布、使用者可取得、渲染核對與人工接受分別回報；沒有可用通道時明說阻礙，不繞過工具拒絕。

核心只保留當前裝置可讀、原稿、必讀路由與阻礙回報，詳細環境與操作判斷移至工程指南。既有模型分工、分支分類、授權、正式批准、資料／服務保護與人工驗收不變。

核心由 8,998 bytes 減至 8,942 bytes（UTF-8，減少 56 bytes）；短原則是首次交付前必需的要求，因此保留常駐，詳細核對方式移至工程指南，並在核心必讀表明列 HTML 交付。

## 已確認規格，服務待啟用

`html-preview` 是另一個已啟動的服務開發目標；下列是已確認方向，不是本 playbook 對已部署服務或可用上傳入口的宣告：

- 提供私人 HTTPS 預覽；承載優先使用 ASUS，沿用 HP 對外入口。主機、網址、認證與路由以後續正式契約及現場核對為準。
- HTML 上傳成功後七天到期。使用者按提前到期按鈕時，新到期時間為 `min(current_expiry, server_now + 300s)`，不得延長原期限。
- 計時與清理由服務端持久化處理，關閉頁面或服務重啟不遺失到期安排；不依賴 Codex 排程。
- 到期只移除線上副本，保留原始 HTML 稿件。此決策不授權刪除本機原稿或其他資料。

本輪不將預定網域或服務寫成上傳預設，不複製完整工程指示詞，也不以規格已確認推定部署、存取控制、到期清理或跨裝置閱讀已驗證。

## 後續整合邊界

由 `html-preview` 的已授權目標先完成部署驗證，發布可引用固定版本的正式接入契約，列明入口、使用授權、存取限制、上傳與到期語義及實測證據。之後再依授權於[服務指南](../guides/service-integration.md)加入精簡路由與必要共通界線，操作細節仍由服務契約維護；核心不常駐網址或上傳命令。

本 playbook 更新不另授權部署、上傳、網路變更、排程或清理，不自動追蹤另一目標，也不修改上游 skill；其他目標既有授權依原可查證來源判定。指南先提交、核心重新釘選與固定版本安裝仍依既有流程，Git、安裝與服務驗證分別回報。
